# Alex Wertpapiere – privates Depot-Dashboard

Dieses Repository ist für **private Nutzung** vorgesehen und enthält persönliche Depotdaten.

## Aktueller Stand

- `index.html` – aktuelles Dashboard (Vollupdate 21.08.2026, inklusive Favicon)
- `dashboard/history/` – historische Dashboard-Stände
- `data/snapshots/` – historische Excel-Look-through-Stände

## Historische Stände

- 17.07.2026 – Look-through Excel
- 19.07.2026 – Dashboard auf Basis des Juli-Stands
- 20.08.2026 – aktualisiertes Dashboard und Look-through Excel
- 21.08.2026 – Kauf Siemens Energy / Transaktionsstand
- 21.08.2026 – vollständiges Marktupdate

## Datenschutz

Das Repository muss **PRIVATE** bleiben. Keine Dateien aus diesem Repository sollen über öffentliche GitHub Pages oder einen öffentlichen Branch veröffentlicht werden.

## Update-Konvention

Bei einem neuen Depot-Update:
1. neuen Daten-Snapshot unter `data/snapshots/YYYY-MM-DD-...` speichern,
2. bisherigen `index.html`-Stand nach `dashboard/history/` archivieren,
3. neue aktuelle Version als `index.html` setzen,
4. Gesamtdepotentwicklung im Dashboard fortschreiben.
